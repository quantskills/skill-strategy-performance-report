# 数据来源与边界

> 对齐 QUANTSKILLS 社区规则 §8：**本 skill 不附带任何市场数据**。净值/基准/成交/持仓均由使用者提供，数据合法性与许可由使用者负责。

## 数据从哪来

| 材料 | 列要求 | 说明 |
|---|---|---|
| 策略净值 | `date, nav`（或 `date, ret`，自动 cumprod） | 权威；有则直接用 |
| 基准净值 | `date, nav`（或 `date, ret`） | 可选；缺则不硬算 |
| 成交记录 | `date, symbol, side, price, shares[, pnl][, commission]` | side 支持 buy/sell/B/买/卖；pnl 列决定 PnL 口径 |
| 持仓市值 | `date, symbol, market_value`（或宽表 date×symbol） | 可选；用于持仓/换手与净值重建 |

输入格式：CSV / TXT / Parquet / XLSX（`pandas` 自动识别）。路径缺失 → 对应输入为 `None`，模块降级。

## 如何供数（推荐路径）

- 实盘策略若有运行环境，可直接导出日频净值 CSV（`date,nav`）——这是最可靠的输入。
- 只有成交流水 + 每日持仓市值时，skill 内部重建净值（**近似**，见 `report-metrics.md` §五）。
- 基准可从指数行情导出（如 pandadata `get_index_daily`），列为 `date,nav`。

## 边界声明

- **本 skill 不做**：拉取行情、模拟实盘撮合、自动重跑回测、验证收益声明。
- **数据合法性与许可由使用者负责**。
- **缺输入 → 对应模块降级**：
  - 无净值且无持仓 → `returns` 降级「无法构建净值曲线」
  - 有持仓无成交 → 满仓法重建（标注近似）
  - 成交缺 `pnl` 列且无法 FIFO 配平 → `trades` 降级「无法计算交易 PnL」
  - 无持仓 → `positions` 降级
  - 样本 < 20 日 → `risk` 降级「样本不足」
- **重建净值为近似**：假设持仓市值完整、现金变动全来自成交；缺省锚定 1.0（收益口径）。报告中口径声明始终标注 `nav_source`。
- **基准选项 ≠ 数据**：`000300.SH` 等只是标签，skill 从不拉取指数；选中基准但无文件 → 基准子项省略并注明，绝不编造。
- **合成数据自检**（`scripts/self_test.py`）仅用于验证脚本正确性，不代表任何真实策略表现。

## 合规声明

本 skill 仅供量化研究、教育与方法论参考。不构成任何形式的投资建议、交易信号或获利保证。使用者据此实盘交易的全部后果由使用者自负。
